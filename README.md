# youtube-assets

Assets de apoio usados na produção de vídeos para o YouTube, organizados por episódio.

## Conteúdo

### 018/
- **markmap.html** — mapa mental interativo (via [markmap](https://markmap.js.org/)) do tema "Roadmap IA 2026", cobrindo:
  - Base comum: fundamentos de IA (tokens, janela de contexto, temperatura, diferenças entre modelos), engenharia de prompt, ferramentas especializadas (imagem, vídeo, música, pesquisa, produtividade) e como aprender com IA (NotebookLM).
  - Decisão entre trilha **User** (uso no trabalho) ou **Builder** (construir e monetizar).
  - Caminho Builder: agentes e automações (n8n), modelos open source (LLaMA, Mistral, Qwen, DeepSeek) e vibe coding (Cursor, Antigravity, Lovable, Bolt).
  - Como se atualizar sem surtar com o excesso de novidades da área.
- **Meditações de Marco Aurélio.pdf** — cópia em PDF da obra "Meditações", de Marco Aurélio.
